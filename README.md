# Surge CS — surge-cs.com

Official website for **Surge CS**, a customer success coaching and toolkit brand founded by Susan Scobie.

## About

Surge CS helps customer success leaders build high-functioning CS teams in 90 days. This repository contains the source code for the Surge CS landing page at [surge-cs.com](https://surge-cs.com).

## The Product

**The Surge CS 90-Day Toolkit** is a complete template toolkit for VP and Head of CS roles, including:

- 90-Day Roadmap & Prioritization Framework
- CS Team Skills Assessment
- Account Plan Template
- Account Health Scorecard
- CSM Performance Rubric
- CS KPI Dashboard
- Customer Engagement Playbook
- Cross-Functional Collaboration Guides
